## 5. 五条硬规矩

**这五条是本仓库真正值钱的东西，比任何结论都值钱。**

### ① 先量，再说做完了

> 独立论文（arXiv 2611.10063，**就是在 build123d/OpenCASCADE 上做的**）测出：
> agent 声称完成 **98%**，其中 **14.1% 静默做错**；
> 加上「先量再声明」的循环后降到 **3.2%**，声明精度 64% → 96%。
> 而且论文明确说：降到 4–5% 靠的是**声明契约**，不是更强的模型。

> *"The expensive failure is a part that builds and renders plausibly while its
> bolt circle sits on the wrong pitch diameter, delivered with 'done, confidence 0.97.'"*

→ 写完 CAD，**先量一个关键关系**（公差、间隙、贴合、孔径），再宣布做完。

### ② 出图和量，两样都要

- **出图**管**形状**（朝向、对不对、像不像）。
- **量**管**数字**（尺寸、位置、公差）。

反例：BenchCAD 说，只给渲染图会让模型**改都不会改了** ——
> *"a render specifies geometry but **not numbers**."*

### ③ 校验器过了 ≠ 引擎加载后还对

- `cad urdf validate` 报 `total mass 0.81 kg`，**MuJoCo 加载后只剩 0.06 kg**。
- 凡是跨边界的检查（URDF→MuJoCo、STEP→别的工具），**都得让目标系统真的跑一遍**。

### ④ 给 MuJoCo 用 MJCF，给 ROS 用 URDF

URDF 装不下：接触排除、关键帧、执行器；而且在 MuJoCo 里还会**静默丢掉固定体的质量**。

### ⑤ 别信星标，也别信「看起来对」

调研实测到的：9 个仓库在 12 分钟内创建、星标全是 492–517；
一个 2,749★ 的仓库只有 README 和 PNG。

## 6. 目录约定

```
agent-3d-lab/
├── docs/          文档（中文）
├── examples/      案例（可分享副本，源码+产出+README）

checks/    量几何的脚本
STEP/      导出的 STEP
img/       渲染图
tmp/       临时（gitignore）
```

## 7. 还没做完的 / 已知的坑

### 欠着的活

- **标定支架**：需要朋友发的那张图。方案 A（加侧带）和 B（前倾 22° 翻脚座）
  要各建一个参数化模型，量出实际用料差异和干涉。
- **MicroDuck 关节限位**：把 MJCF 里 15 个关节的 range 逐条对回 XL330 舵机规格。
  已经知道的一条不一致：`mouth` 是个舵机但**没有对应的 MJCF 关节**，
  所以它永远不会出现在烘焙结果里。
- **夹爪**：`CLOSE_TRAVEL` / `OPEN_TRAVEL` / `DRIVE_FORCE_N` / `DRIVE_SPEED_MPS`
  都是**占位符**，得换成真实驱动器的手册值。
- **夹爪机构**：手指（38 mm）够不到掌板的导轨条（y = ±22），所以手指其实没搭在导轨上。

### 会再踩的坑

| 坑 | 在哪 |
| --- | --- |
| `mass()` 是「总重」不是「零件重」（含 point mass） | `docs/07` §2 |
| `point_mass` 只能挂 part，不能挂 assembly | `docs/07` §2 |
| `cad step snapshot --camera` **没有 `side`**，用 `right` | `docs/03` |
| URDF 里线性关节的长度单位是**米** | `docs/03` §4 |
| MuJoCo 的 `mesh_vert` 已经是 `(N,3)`；网格会被重定心，算包围盒要变换真实顶点 | `docs/07` §9 |
| OCCT 按**内存地址**合并顶点 → 同一脚本跨进程几何可能不同 → **STEP 要入库** | `docs/09` §2.4 |
| PyPI simple index 不是版本排序的 → `sort -V \| tail -1` | `research/raw/README.md` |

## 8. 给下一个 session 的一句话

> **这个仓库的价值不在结论，在方法。**
> 结论会过期（工具链在改、业界在动、文档里的数字是 2026-11 的快照）；
> 但「先量再说做完了」「出图和量都要」「校验器过了不等于引擎加载后还对」
> 这三条不会过期。

> **现象 → 怎么发现的 → 出处（issue 号 / 论文号 / 官方文档）→ 修法**。
