## 核心链路（已就绪）

| 组件 | 版本 | 作用 |
| --- | --- | --- |
| `cadgen` | 0.6.5 | CAD 内核封装：建模 / 校验 / 出图 / 起查看器 |
| `build123d` | 0.11.1 | 参数化建模（OpenCascade 上的 Python DSL） |
| `OCP` | (随 cadgen) | OpenCascade 的 Python 绑定，真正算几何的内核 |
| `ocpsvg` | 0.6.0 | STEP ↔ SVG |

| `playwright` + chromium | 1.63.0 | **渲染后端**：出图和 Viewer 都靠它 |
| `uv` / `uvx` | — | 跑 MCP server 用 |
| `node` / `npx` | — | `npx skills add` 装 skill 用 |
| `gh` | 2.100.0 | 建仓 / 协作 |
| `mujoco` | 已装 | URDF → 仿真，验证关节限位和碰撞 |

> ⚠️ **playwright 的 chromium 是硬依赖**。pip 装不上浏览器，
> 必须另外跑一次 `python -m playwright install chromium`。
> 少了它，`cadgen ... snapshot` 会挂，Viewer 也起不来。

## 已装的 13 个 CAD skill

全部来自同一个仓库：[`earthtojake/text-to-cad`](https://github.com/earthtojake/text-to-cad)（MIT）。
装在 `3D-stp/.claude/skills/`（同时镜像到 `.agents/` `.trae/` `.windsurf/` 等多个 agent 工具目录，
由 `skills-lock.json` 记录来源和哈希）。

| skill | 干什么 | 什么时候用 |
| --- | --- | --- |
| `cad` | **主入口**：建/改/量几何，出 STEP/STL/3MF/GLB | 几乎每次建模都用 |
| `cad-viewer` | 起本地浏览器查看器，给 review 链接 | 想自己转着看模型时 |
| `step-parts` | 查现成标准件（螺丝/轴承/电机/连接器）的 STEP | 不想自己画螺栓时 |
| `dxf` | 2D 图纸、切割路径、钣金展开 | 做平面件时 |
| `engineering-drawing` | 出带真实尺寸标注的工程图 PDF | 要交付图纸时 |
| `dfm` | 钣金/CNC/注塑可制造性审查 | 决定怎么加工时 |
| `dfam-check` | 3D 打印可打印性（悬垂/壁厚/支撑） | 要打出来时 |
| `gcode` | 切片出 gcode 并静态校验 | 要打印时 |
| `urdf` | 机器人描述：连杆、关节、惯量、网格引用 | 做 URDF 时 |
| `srdf` | MoveIt 语义：规划组、末端执行器、禁碰 | 做 MoveIt 时 |
| `sdf` | 仿真世界/模型描述 | Gazebo 时 |
| `sendcutsend` | 上 SendCutSend 下单前的预检 | 真要下单时 |
| `bambu-labs` | 本地 Bambu 打印机接管 | 有打印机时 |

### 怎么更新

```bash
# 项目级（推荐，锁在 3D-stp 里）
npx skills add earthtojake/text-to-cad --skill cad --agent claude-code

# 或者按插件装，一次给全套
claude plugin marketplace add earthtojake/text-to-cad#latest
claude plugin install text-to-cad@earthtojake
```

装完用 `cadgen doctor <skill目录>` 核对版本是否对得上——
**文档会悄悄漂移**，版本不匹配时 skill 里的示例和实际 CLI 对不上。

## 还缺什么（按用途选装）

### A. 想让 Agent 直接"看见"并操作 3D 软件

| 装什么 | 怎么装 | 换来的能力 |
| --- | --- | --- |
| **Blender** | `brew install --cask blender` | 有机体/曲面建模、场景、渲染。装完可接 MCP，Agent 能执行 Blender Python |
| **FreeCAD** | `brew install --cask freecad` | GUI 参数化 CAD + 机器人装配可视化，有 MCP server |

> MCP for Blender 有个**安全点**要记住：社区版的 `execute_blender_code`
> 是**无沙箱执行任意 Python**。开 `BLENDER_MCP_SAFE_MODE=1` 更稳。

### B. 想真的打印出来

| 装什么 | 怎么装 |
| --- | --- |
| OrcaSlicer 或 PrusaSlicer | `brew install --cask orcaslicer` |

`gcode` skill 需要真实切片器 CLI 才能出片；没有它只能做静态检查。

### C. 想做网格层面的活

| 装什么 | 怎么装 | 用途 |
| --- | --- | --- |
| `trimesh` | `pip install trimesh` | 网格分析/修整/凸包（做碰撞体最常用） |
| `yourdfpy` | `pip install yourdfpy` | URDF 解析与遍历，比裸 XML 顺手 |
| `pyvista` / `vtk` | `pip install pyvista` | 网格可视化 |

### D. 想跑仿真

| 装什么 | 用途 |
| --- | --- |
| **MuJoCo**（已装） | macOS 上最省事的仿真器，URDF 直接丢进去，headless 跑 |
| Gazebo / Isaac Sim | 完整，但 Isaac 要 NVIDIA GPU，Mac 上只能看不能跑 |

### E. 想玩 AI 生成网格

| 装什么 | 现实情况 |
| --- | --- |
| 本地跑 Hunyuan3D / TRELLIS | **需要 NVIDIA GPU**（8–24 GB 显存），Mac 上不现实 |
| 走 API（Meshy / Tripo / Zoo.dev） | Mac 完全能跑，但要钱，出的网格**不可参数化** |

> 详见 `docs/01-技术路线全景.md` 的结论：**机械件别走这条路**，
> 走参数化代码。

## 一条命令装齐核心

```bash
python3 -m pip install -r <skill目录>/requirements.txt
python3 -m playwright install chromium
```

`<skill目录>` 就是 `3D-stp/.claude/skills/cad/`（或任一已装 skill 目录）。
