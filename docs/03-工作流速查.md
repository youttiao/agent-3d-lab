# 工作流速查

把「用 Agent 做 3D」拆成可重复的步骤。核心思想：**Agent 写代码，不写鼠标动作；几何由内核算，结论靠看图验证。**

> 本文对应 **text-to-cad 0.11.x**（命令 `cad`）。0.6 时代的写法见
> [`05-升级到0.11.md`](05-升级到0.11.md) 的对照表。

---

## 0. 一句话路线

```
需求 → 读参考件 → 写参数化模型 → cad run 生成 STEP → 出图看 → 改 → 验证 → 交付
                 ↑                                        ↓
                 └────────── 尺寸对但形状不对 ←──────────┘
```

---

## 1. 建模（STEP）

### 目录约定

```
<project>/
  src/            # 一个模型一个入口文件
  STEP/           # 输出 + imported/（厂商原始件）
  STL/ GLB/ DXF/  # 其他格式
  checks/         # 校验脚本
  tmp/            # 探索性产物（不入库）
```

### 模型文件长什么样

```python
# src/plate.py
from __future__ import annotations

import build123d as bd
from cad import step

WIDTH = 60.0


@step("../STEP/plate.step")
def plate():
    body = bd.Box(WIDTH, 40, 4)
    body.label = "plate"
    return body


if __name__ == "__main__":
    plate()
```

### 两种模式：模型页 vs 文件页

| | 模型页（`@model`） | 文件页（`@step`） |
| --- | --- | --- |
| 每次 run | 页面更新，**不写文件** | **文件一起写出** |
| 拿到的引用 | `made_by` 指向函数/文件/行号 | 没有——文件不知道是哪个模型做的 |
| 适合 | 想在浏览器里看、想让人直接调参数 | 项目本来就在文件上迭代（我们这种） |

我们的项目走**文件页**：`@step("../STEP/x.step")`，路径相对脚本本身。

### 规矩（踩过的坑）

| 规矩 | 为什么 |
| --- | --- |
| 单位 mm，XY 平面 + Z 向上 | 跟 STEP/URDF/打印切片器一致，少一次换算 |
| `Box` 默认 `align=CENTER`（几何居中） | 想贴 Z=0 必须写 `align=(CENTER, CENTER, MIN)` |
| **内核对象只在函数体里读** | `bd.Align.CENTER` 写在模块层，会让脚本自己的进程也加载内核，每次 run 多花 2～3 秒 |
| 文件装饰器**取代** `@model`，不能并存 | 上游明确的规定 |
| 一个 `.py` 一个模型入口 | 文件名 = 输出名主干：`src/plate.py` → `STEP/plate.step` |
| 关键尺寸提成模块级常量 | 别人（包括下一个 Agent）不用读几何就能改 |
| 公共几何写成普通工厂函数 | 装饰函数只负责"选一个配置" |
| 导入用 `from __future__ import annotations` | 注解里出现 `bd.Xxx` 时不炸 |

### 命令

```bash
cad run src/plate.py                                # 生成 STEP + 打印 id 和 view 链接
cad run src/plate.py                                # 再跑一次 → 应报 nothing ran（幂等）
cad step snapshot STEP/plate.step tmp/plate.png     # 出图（不用起 server）
cad model snapshot <id> tmp/plate.png               # 出图（用 server 里的文档）
```

`cad run` 会打印：

```
built src/plate.py::plate warm in 0.09s: bodies 1 run, 1 replayed; ...
  parts 1 · bounds 60 × 40 × 4 mm · joints 0 · sequences 0
  id: 58ea2d68-…
  view: http://127.0.0.1:3245/58ea2d68-…?token=…
```

- **浏览器打开 `view` 链接**就能交互查看（转、剖、爆炸、Quick Edit）
- `parts N · bounds W × D × H mm` 这行就是**尺寸自检**——改完扫一眼

### 让人直接调参数

```python
WALL = model.param("wall", 2.0, min=1, max=5, unit="mm")
HOLES = model.param("holes", 4, min=2, max=8)
```

改一个数就是改脚本里的那个数字再 run；viewer 里保存也会重写脚本里的数字。

## 2. 看图验证（不能省）

**尺寸对 ≠ 形状对。** 每改一次几何就要出一张图。

```bash
cad step snapshot STEP/plate.step tmp/plate.png                    # 默认等轴视角
cad step snapshot STEP/plate.step tmp/top.png --camera top         # 预设视角
cad step snapshot STEP/plate.step tmp/x.png --camera 225:-30       # 方位角:仰角
cad step snapshot STEP/plate.step tmp/x.png --display hidden-line  # 线框模式
cad step snapshot STEP/plate.step tmp/x.png --preview              # 写实预览（给人看的）
```

> **本机实测**：OCCT 自带的无头光栅渲染在这台 Mac 上直接可用——
> 1600×1200 出图 **0.07～2 秒**，**不用浏览器、不用 GPU**。
> （0.6 时代靠 Playwright + Chromium，现在不需要了。）

视角预设：`iso` `front` `back` `left` `right` `top` `bottom`，或 `方位:仰角`。

## 3. 分析别人的模型

```python
from cad import step
from cad.build123d import leaves

tree = step.read("imported/vendor_part.step")
for part in leaves(tree):
    bb = part.bounding_box()
    print(part.label, bb.min, bb.max, bb.size)
```

`leaves(tree)` 给的是**在树里就位**的每个零件（带自己的标签、颜色、材料）。
拿到包围盒和尺寸后，**不要凭感觉建模**：
逐个特征去量（安装孔位置、销孔、厚度、槽深），把量到的值写成常量表，再动手。

> ⚠️ `read_scene` / `read_step` 这两个函数 **0.8 起就没了**。

完整例子见 [`examples/robotiq-v-finger`](../examples/robotiq-v-finger/README.md)。

## 4. 机器人描述（URDF / SRDF / MJCF）

和 CAD 是**两套规矩**，别混。

### 铁律

1. **`.urdf` 文件本身是唯一真相**。直接编辑 XML，别造 Python 生成管线。
2. **动手前先写"设计台账"**（design ledger）：坐标系、关节轴、单位、假设，
   以注释块形式放在 `.urdf` 文件头部。
3. **框架语义别搞混**：joint origin、link frame、joint axis、
   visual/collision/inertial origin 参照的坐标系各不相同。
4. **绝不手搓算出来的数**（惯性张量、质心、单位换算、镜像变换）。
5. **每次改完必须校验**。

### 新能力：从 CAD 生成

0.11 里 robot-simulation skill 提供了**从 CAD 模型直接导出 URDF/MJCF**：

```bash
cad model export <id> robot.urdf
cad model export <id> robot.xml      # MJCF
```

**关节限位可以自动推**：

```bash
cad model ranges <id>
```

> 让每个关节**单独转**，直到子连杆撞上父连杆，打印每个止点（度或毫米）。
> 这是**几何**的限位；**舵机自己的行程更窄时，以数据手册为准**。

### 零位的约定（很容易踩）

> **装配位就是每个关节的零位。** 关节限位 = 关节量程 − 装配时的角度：
> 一个指头在 0°~40° 量程里以 30° 装配，写出去就是 −30°~+10°，**不报警告**。
>
> 有控制器的，描述文件的零位应该对齐控制器的零位。

### 命令

```bash
cad urdf validate robot.urdf
cad urdf snapshot robot.urdf tmp/robot.png
cad srdf validate robot.srdf --urdf robot.urdf
cad mujoco check robot.xml              # MuJoCo 模型健康检查
```

## 5. 交付前的检查清单

- [ ] `cad run src/<model>.py` 能跑通，再跑一次应报 `nothing ran`
- [ ] 出过图，并且**人眼看过**
- [ ] `cad run` 打印的 `bounds` 和设计对得上
- [ ] 尺寸常量集中、命名能看懂
- [ ] 文件头有坐标系与单位说明
- [ ] 需要的话出了 STL/3MF
- [ ] 打印件跑过可打印性检查（`cad model dfm`）
- [ ] URDF 跑过 `cad urdf validate`
- [ ] 几何改过之后，比对过新旧（见 `checks/compare_steps.py`）
