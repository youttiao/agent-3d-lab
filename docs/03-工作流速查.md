# 工作流速查

把「用 Agent 做 3D」拆成可重复的步骤。核心思想：**Agent 写代码，不写鼠标动作；几何由内核算，结论靠看图验证。**

---

## 0. 一句话路线

```
需求 → 读参考件 → 写参数化模型 → 跑生成 STEP → 出图看 → 改 → 验证 → 交付
                 ↑                                        ↓
                 └────────── 尺寸对但形状不对 ←──────────┘
```

---

## 1. 建模（STEP）

### 目录约定

```
<project>/
  src/            # 一个模型一个入口文件
  STEP/           # 输出 + imported/（厂商原始件）
  STL/ GLB/ DXF/  # 其他格式
  checks/         # 校验脚本
  tmp/            # 探索性产物（不入库）
```

### 模型文件长什么样

```python
# src/plate.py
from cadgen import build123d as bd
from cadgen import step

WIDTH = 60.0


@step(out="../STEP/plate.step")
def plate():
    body = bd.Box(WIDTH, 40, 4)
    body.label = "plate"
    return body


if __name__ == "__main__":
    plate()
```

### 规矩（踩过的坑）

| 规矩 | 为什么 |
| --- | --- |
| 单位 mm，XY 平面 + Z 向上 | 跟 STEP/URDF/打印切片器一致，少一次换算 |
| `Box` 默认 `align=CENTER`（几何居中） | 想贴 Z=0 必须写 `align=(CENTER, CENTER, MIN)` |
| 装饰器 `out=` **相对脚本**，不是相对 cwd | 否则换个目录跑就写到别处去了 |
| 一个 `.py` 一个模型入口 | 文件名 = 输出名主干：`src/plate.py` → `STEP/plate.step` |
| 关键尺寸提成模块级常量 | 别人（包括下一个 Agent）不用读几何就能改 |
| 公共几何写成普通工厂函数 | 装饰函数只负责"选一个配置"，不要塞逻辑 |
| 导入用 `from __future__ import annotations` | 注解里出现 `bd.Xxx` 时不炸 |
| 延迟导入 `bd` 属性 | 避免 import 时就碰内核 |

### 命令

```bash
python src/plate.py                                    # 生成 STEP
python src/plate.py                                    # 再跑一次 → 应报 current（幂等）
cadgen step snapshot STEP/plate.step tmp/plate.png     # 出图
cadgen step build STEP/plate.step OUT.step              # 格式转换
```

## 2. 看图验证（不能省）

**尺寸对 ≠ 形状对。** 每改一次几何就要出一张图。

```bash
# 单张
cadgen step snapshot STEP/plate.step tmp/plate.png

# 本地交互查看器（浏览器里能转、能剖）
cd <项目根> && cadgen viewer --host 127.0.0.1 --json
```

> Viewer 一次服务**一个目录**（启动时的 cwd），复用键是
> `realpath(cwd) × cadgen 版本 × 客户端内容摘要`。
> 所以**从你想看的那个目录启动**，别在 skill 目录里起。
> 端口从 3245 往上找，**不要自己猜端口，读它打印出来的 URL**。

## 3. 分析别人的模型

```python
from cadgen import read_scene, read_step

scene = read_scene("imported/vendor_part.step")
print(len(scene.shapes()))
for s in scene.shapes():
    bb = s.bounding_box()
    print(bb.min, bb.max, bb.size)
```

拿到包围盒和尺寸后，**不要凭感觉建模**：
逐个特征去量（安装孔位置、销孔、厚度、槽深），把量到的值写成常量表，再动手。

完整例子见 [`examples/robotiq-v-finger`](../examples/robotiq-v-finger/README.md)。

## 4. URDF / 机器人描述

和 CAD 是**两套规矩**，别混。

### 铁律

1. **`.urdf` 文件本身是唯一真相**。直接编辑 XML，别造 Python 生成管线。
2. **动手前先写"设计台账"**（design ledger）：坐标系、关节轴、单位、假设，
   以注释块形式放在 `.urdf` 文件头部。
3. **框架语义别搞混**：joint origin、link frame、joint axis、
   visual/collision/inertial origin 参照的坐标系各不相同。
4. **绝不手搓算出来的数**（惯性张量、质心、单位换算、镜像变换）——
   闭式公式算，或者写个一次性脚本算。
5. **每次改完必须校验**：`cadgen urdf validate`，不通过就修到通过。

### 流程

```
读/建设计台账 → 备好网格资产 → 编辑 XML → 算惯性 → validate → viewer 逐关节看
```

### 命令

```bash
cadgen urdf validate robot.urdf
cadgen urdf snapshot robot.urdf tmp/robot.png
cadgen srdf validate robot.srdf --urdf robot.urdf
```

网格资产要求：**一个 link 一个网格**，且网格要**在 link 坐标系里导出**。

## 5. 交付前的检查清单

- [ ] `python src/<model>.py` 能从干净状态跑通，第二次跑报 `current`
- [ ] 出过图，并且**人眼看过**
- [ ] 尺寸常量集中、命名能看懂
- [ ] 文件头有坐标系与单位说明
- [ ] 需要的话出了 STL/3MF
- [ ] 打印件跑过 `dfam-check`（悬垂、壁厚）
- [ ] 钣金件跑过 `dfm`（折弯、拔模）
- [ ] URDF 跑过 `cadgen urdf validate`

## 6. 相关 skill

| skill | 干什么 |
| --- | --- |
| `cad` | 建模主入口（STEP 优先） |
| `cad-viewer` | 起本地查看器，给 review 链接 |
| `urdf` / `srdf` / `sdf` | 机器人描述 |
| `dxf` | 2D 图纸 / 激光切割 / 钣金展开 |
| `engineering-drawing` | 出带尺寸标注的工程图 PDF |
| `dfm` / `dfam-check` | 可制造性 / 可打印性审查 |
| `gcode` | 切片出 gcode |
| `step-parts` | 查现成标准件（螺丝、轴承、电机…）的 STEP |
| `sendcutsend` | 上传到 SendCutSend 下单前的预检 |
| `bambu-labs` | 本地 Bambu 打印机打 gcode |

来源统一是 [`earthtojake/text-to-cad`](https://github.com/earthtojake/text-to-cad)。
